## 📦 Open Source

### 🖊️ [signature-pad-js](https://github.com/niel-blanca/signature-pad-js) · [npm](https://www.npmjs.com/package/@niel-blanca/signature-pad)
A modern, lightweight, **zero-dependency** signature pad built with Vanilla JavaScript and the Canvas API.
- Smooth Bezier curve drawing with touch & pen support
- Undo / redo history
- Export to PNG, JPG, SVG and JSON
- Method chaining and full TypeScript support

```bash
npm install @niel-blanca/signature-pad
```
